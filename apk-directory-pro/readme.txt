Modern WordPress theme for APK and app directory sites. Requires APK Directory Core plugin.

== Description ==

Clean app-store interface with homepage sections, app archives, live search, single app pages with version history, secure downloads, reviews, and blog support.

== Installation ==

1. Install and activate APK Directory Core plugin first.
2. Upload and activate this theme.
3. Configure via Appearance → Customize.
