WebP Lab

Drop JPG or PNG files. Get smaller WebP downloads — all in your browser.

Convert images to WebP

    How this tool works

    1. HTML builds the UI (drop zone, slider, buttons).
    2. JavaScript reads the image file you choose.
    3. The browser draws it onto a hidden canvas.
    4. canvas.toBlob('image/webp') encodes WebP.
    5. You download the new file — nothing is uploaded to a server.

    Runs locally in your browser. Open index.html and start converting.
