Hello, World! 👋

Congratulations — you are looking at a web page that you can change yourself. Everything you see here comes from the file 01-hello-world.html.

Now open this file in your editor and look at the source code. Notice the comments (they start with <!--) — they explain every part of the page.

The rules so far

Only four ideas make up this whole page:

1. A page starts with <!DOCTYPE html> — it tells the browser "this is modern HTML".
2. <head> holds information about the page.
3. <body> holds what visitors see.
4. Content is wrapped in tags like <p>...</p> that describe what it is.

🏋️ Your exercises

Do these in your editor, saving and refreshing the browser after each one:

1. Change the text inside the <h1> to greet yourself by name.
2. Change the <title> in the head and watch the browser tab update.
3. Add a brand-new paragraph at the bottom of the body describing why you want to learn HTML.
4. Break something on purpose: delete a closing tag like </p>, refresh, and see what happens. Then fix it. (Browsers are forgiving — they try to guess what you meant — but relying on that leads to messy bugs later.)
