Your hands-on HTML path

HTML is the structure of every webpage. Tags mark up content so browsers know what is a heading, a link, an image, or a form.

Lessons

  1. 01 — Page skeleton DOCTYPE, html, head, body
  2. 02 — Text & headings h1–h6, p, strong, em, br
  3. 03 — Links & images a, img, href, src, alt
  4. 04 — Lists ul, ol, li
  5. 05 — Tables table, tr, th, td
  6. 06 — Forms form, input, label, button
  7. 07 — Semantic HTML header, nav, main, section, footer
  8. 08 — Mini project Build a personal profile page

How to practice

  1. Open a lesson file in your editor.
  2. Open the same file in a browser (double-click or Live Preview).
  3. Change something, save, refresh — see what happened.
  4. Do the “Your turn” tasks at the bottom of each lesson.

Tip: HTML = structure. CSS = style. JavaScript = behavior. Start with structure.
