Send it

After you submit, look at the address bar: the field values appear there as ?username=...&email=.... That is the form data being "sent" — with a real server, it would be processed instead of just reloading the page.

🏋️ Your exercises

  1. Try submitting with an empty username — read the browser's error message. Then type an invalid email (like "hello") and submit.
  2. Add a phone number field (type="tel") with a label.
  3. Add a checkbox: "I agree to the terms" — make it required and see what happens when you submit without checking it.
  4. Build a tiny pizza-order form from scratch in a new file: name, size (radio buttons), toppings (checkboxes), delivery date, and a submit button.
