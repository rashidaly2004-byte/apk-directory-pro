Lesson 3: Links and Images

Links

A link is an <a> element. The href attribute says where it goes; the text between the tags is what the user clicks. For example, here is a link to the MDN HTML documentation — the best reference site for web developers. Bookmark it!

Three kinds of link destinations

Absolute: https://www.wikipedia.org — a complete address to another site.
Relative: 02-text.html — a path relative to the current file. This is how you link between pages of your own site.
Fragment: #exercises — jumps to the element on this page whose id is "exercises" (scroll down after clicking!).

Images

<img> is a void element (no closing tag) with two attributes you should always set:

• src — where the image file lives (absolute or relative, just like links).
• alt — a text description, read aloud by screen readers and shown if the image fails to load. Describe the image's content, e.g. alt="A cat sleeping on a laptop".
