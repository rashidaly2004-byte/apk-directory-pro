03 — Links & images

Links connect pages. Images show pictures. Both need an attribute that points to a URL or file path. 

<!-- Link to another page or site -->
<a href="https://developer.mozilla.org/">MDN Web Docs</a>

<!-- Open in a new tab -->
<a href="https://example.com" target="_blank" rel="noopener">
  Example
</a>

<!-- Image: always include alt text -->
<img
  src="https://picsum.photos/400/240"
  alt="A random landscape photo"
  width="400"
  height="240"
/>

Live demo

Visit MDN HTML docs.

Key attributes

href
Where the link goes (URL or relative path like index.html).
src
Where the image file is.
alt
Text description for screen readers & when the image fails to load.
