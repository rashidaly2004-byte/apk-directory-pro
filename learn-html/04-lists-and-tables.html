Lesson 4: Lists and Tables

Unordered lists

Use <ul> when order doesn't matter. Each item is an <li> (list item):

  • HTML — structure
  • CSS — appearance
  • JavaScript — behavior

Ordered lists

Use <ol> when the order matters:

  1. Open the file in your editor
  2. Change something
  3. Save
  4. Refresh the browser

Nested lists

Put a whole <ul> inside an <li> to create sub-items:

  • Frontend
    • HTML
    • CSS
  • Backend
    • Databases
    • APIs

Description lists

For glossaries and key–value pairs:

Element
Opening tag + content + closing tag.
Attribute
A name="value" setting inside an opening tag.
Void element
An element with no content or closing tag, like <img> or <br>.

Tables

A table is built row by row. The pieces: <table> wraps everything, <tr> is a table row, <th> is a header cell, and <td> is a data cell. <thead> and <tbody> group the header and body rows.

One warning: in the old days people used tables to lay out entire pages. Don't — tables are for data. Page layout is CSS's job (your next adventure after HTML).

🏋️ Your exercises

  2. Write a numbered recipe (real or silly) with at least five steps.
  3. Create a nested list: your three favorite music genres, each with two artists under it.
  4. Build a table of your typical week: columns for Day, Main task, and Mood. Add at least three rows and a caption.
