08 — Mini project: profile page

Build one page that uses everything you’ve learned. No CSS required — structure first.

Requirements checklist

  • Valid page skeleton (DOCTYPE, html, head, body)
  • One <h1> with your name
  • Short About section with 2 paragraphs
  • Photo (or placeholder image) with alt
  • Unordered list of skills
  • Ordered list: “How I learn”
  • Link to at least one external site
  • A simple contact form (name, email, message)
  • Semantic layout: header, nav, main, section, footer

Starter sketch (copy & improve)

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Rashid — Profile</title>
  </head>
  <body>
    <header>
      <h1>Your Name</h1>
      <nav>
        <a href="#about">About</a>
        <a href="#skills">Skills</a>
        <a href="#contact">Contact</a>
      </nav>
    </header>

    <main>
      <section id="about">
        <h2>About</h2>
        <p>Write about yourself here.</p>
      </section>

      <section id="skills">
        <h2>Skills</h2>
        <ul>
          <li>HTML</li>
        </ul>
      </section>

      <section id="contact">
        <h2>Contact</h2>
        <form>
          <!-- your inputs -->
        </form>
      </section>
    </main>

    <footer>
      <p>Built while learning HTML.</p>
    </footer>
  </body>
</html>

Save it as profile.html and keep iterating until the checklist is done.

What next?

  1. Learn CSS to style your profile page.
  2. Bookmark MDN HTML.
  3. Practice: rebuild a simple site you like using only HTML structure.
