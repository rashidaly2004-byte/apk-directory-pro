# Learn HTML by Doing

A hands-on HTML course made of real `.html` files. Each lesson is a working
web page with the explanations written as comments right next to the code
they describe, plus a small challenge at the bottom.

## How to use this

1. Open any lesson file directly in your browser to see the rendered result
   (double-click the file, or drag it into a browser tab).
2. Open the same file in your editor to read the code and comments.
3. Edit the file, save, and refresh the browser to see your change instantly.
4. Do the "Try it yourself" challenge at the bottom of each lesson before
   moving to the next one.

No build tools, no server, no installs required — just a browser and a text
editor.

## Suggested order

Go through the lessons in order (1 → 8). Lessons 1–7 each introduce one
concept at a time. Lesson 8 is a starter template with instructions instead
of finished code — that's where you apply everything you learned.

## After this

Once you're comfortable with these lessons, natural next steps are:

- **CSS** — to style the pages you're now able to build.
- **The browser DevTools** (right-click → "Inspect") — to see how your HTML
  is actually rendered and to experiment live.
- **A little JavaScript** — to make pages interactive.
