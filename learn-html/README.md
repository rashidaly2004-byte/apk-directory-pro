# Learn HTML — a hands-on course

A self-paced HTML course where **every lesson is a web page you can open,
read, break, and fix**. No tools to install: you only need a browser and a
code editor.

## How to use this course

1. Open a lesson file in your **browser** (double-click it, or drag it onto
   a browser window) and read the page.
2. Open the same file in your **editor**. The source code is heavily
   commented — the comments are the other half of the lesson.
3. Do the exercises at the bottom of each lesson **in the lesson file
   itself**: edit, save, refresh the browser, repeat.

That edit → save → refresh loop is the whole workflow. There is no build
step and nothing to compile.

## The final project

When you finish lesson 6, build a complete profile page from scratch:

- Start here: [`exercises/my-profile-starter.html`](exercises/my-profile-starter.html)
  — a skeleton with TODOs guiding you through it.
- Compare afterwards: [`exercises/my-profile-solution.html`](exercises/my-profile-solution.html)
  — one possible solution. Don't peek early!

## Tips

- **DevTools is your friend.** Press `F12` in the browser to inspect any
  page — including your own — and see its structure.
- **When stuck, check [MDN](https://developer.mozilla.org/en-US/docs/Web/HTML)** —
  the reference used by professional web developers.
- **Validate your work** at [validator.w3.org](https://validator.w3.org/#validate_by_upload)
  to catch unclosed tags and other mistakes.

## What's next after HTML?

1. **CSS** — make your pages look good (layout, colors, fonts).
2. **JavaScript** — make your pages interactive.

HTML + CSS + JavaScript are the three languages of the web; you're one
third of the way there.
