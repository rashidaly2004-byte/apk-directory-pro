# Learn HTML

Hands-on HTML mini-course. Open `index.html` in a browser, then work through the lessons in order.

## Quick start

1. Open `learn-html/index.html` in your browser.
2. Open the same folder in your editor.
3. For each lesson: read → try the demo → do **Your turn**.
4. Capstone: build `profile.html` from lesson 08.

## Lesson map

| #  | File                 | Focus                          |
| -- | -------------------- | ------------------------------ |
| 01 | `01-skeleton.html`   | DOCTYPE, html, head, body      |
| 02 | `02-text.html`       | Headings, paragraphs, emphasis |
| 03 | `03-links-images.html` | Links & images               |
| 04 | `04-lists.html`      | ul, ol, li                     |
| 05 | `05-tables.html`     | Tables                         |
| 06 | `06-forms.html`      | Forms & inputs                 |
| 07 | `07-semantic.html`   | header, nav, main, footer      |
| 08 | `08-project.html`    | Build a profile page           |

## Learning loop

Edit → save → refresh. That’s how HTML sticks.

When you’re ready for styling, we’ll add a CSS track next.
