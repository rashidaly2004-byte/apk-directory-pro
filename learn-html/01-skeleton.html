01 — Page skeleton

Every HTML page starts with the same bones. Memorize this shape — you’ll write it constantly. 

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My first page</title>
  </head>
  <body>
    <!-- visible content goes here -->
  </body>
</html>

What each piece does

<!DOCTYPE html>
Tells the browser: “this is modern HTML.”
<html>
Root of the document. lang="en" helps accessibility & SEO.
<head>
Metadata (title, charset, CSS links). Not shown on the page.
<body>
Everything the user sees.

Tags vs elements

A tag is the markup like <p>. An element is the whole thing: <p>Hello</p>.

Most elements have an opening and closing tag. Some are self-closing (void): <img />, <br />, <meta />.
