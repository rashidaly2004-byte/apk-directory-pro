Learn HTML by writing it

Eight short lessons. Every one of them is a real HTML page, so you can read the lesson in your browser and then open the same file in your editor to see exactly how it was built. Nothing to install, no build step, no framework.

How to use this course

Open lessons/01-your-first-page.html in a browser (double-clicking the file works fine) and read it. Then keep two windows side by side: the browser and your editor. Change something in the file, save, and refresh the browser. That loop — edit, save, refresh — is the whole job.

If you'd rather serve the files over http:// instead of file://, run python3 -m http.server from the html-course folder and visit http://localhost:8000. You'll need this later when you start loading images and stylesheets from other folders.

The single most useful habit: right-click any page on the web and choose View Page Source. Every site you admire is HTML that someone typed. Reading other people's markup is how the shapes start to feel obvious.

Lessons

  1. Lesson 01 Your first page What an element is, what the doctype does, and why every page has a head and a body.
  2. Lesson 02 Text: headings, paragraphs, lists The elements you'll reach for constantly, plus quotes, line breaks and character entities.
  3. Lesson 03 Links and paths Absolute vs relative URLs, linking between your own pages, anchors, mail links, new tabs.
  4. Lesson 04 Images and media The img element, writing good alt text, figures with captions, audio and video.
  5. Lesson 05 Page structure and semantics header, nav, main, section, article, aside, footer — and when a plain div is the right answer.
  6. Lesson 06 Tables Rows, cells, header cells and scope, spanning columns, and what tables are not for.
  7. Lesson 07 Forms and inputs Labels, input types, selects, checkboxes and radios, and free browser validation.
  8. Lesson 08 The head, accessibility and shipping Metadata, social previews, favicons, the accessibility rules that matter most, validators.

Exercises

Each exercise is a starter.html file with numbered TODO comments and a solution.html next to it. Do the starter first and only peek at the solution when you're stuck or when you want to compare.

  • Exercise 01 · after lesson 02 Recipe card Headings, paragraphs, an ordered list and an unordered list on one page.
  • Exercise 02 · after lesson 05 Profile page A semantic layout with navigation, an image with real alt text, and internal links.
  • Exercise 03 · after lesson 07 Signup form Correctly labelled fields, sensible input types, required fields and a fieldset.

What this course leaves out

HTML decides what things are. CSS decides how they look, and JavaScript decides what they do. This course is only the first of those three, on purpose — HTML is small enough to learn properly in an afternoon, and it's much easier to learn CSS once you already know what you're styling. Lesson 08 points you at where to go next.
